# Globe Puzzle

3D globe puzzle: an antique desk globe with countries, seas and ocean currents. Scatter Europe and put it back together.
Russian and English.

**Play:** https://tamarakorotysh.github.io/globe-puzzle/

- `npm install`, `npm run dev` → http://localhost:5173
- Styles: `?style=antique` (default), `?style=space`, `?style=toy`
- Every push to `main` deploys the site via GitHub Actions.
