# Globe Puzzle — 3D-глобус-пазл

Веб-приложение (PWA): 3D-глобус с границами стран, столицами, флагами и фактами.
Кнопка «Рассыпать» — страны и океаны разлетаются как пазлы, остаётся шар-основа,
игрок собирает глобус заново. Позже — упаковка в App Store / Google Play через Capacitor.

**Языки интерфейса и контента: русский и английский** (переключатель, по умолчанию — язык браузера).

## Стек
- Vite + React + TypeScript, React Three Fiber (Three.js), drei
- Физика рассыпания: Rapier (@react-three/rapier)
- Границы: Natural Earth 1:50m (упрощать через mapshaper), спорные территории — решить на этапе 1
- Океаны: Marine Regions или «всё, что не суша», нарезанное на крупные куски
- Флаги: flag-icons (SVG)
- Столицы/данные: Natural Earth + REST Countries → один свой `data/countries.json`
- Факты: генерация нейросетью, ru + en, выборочная проверка
- i18n: простые JSON-словари `src/i18n/ru.json`, `en.json` (без тяжёлых библиотек)
- Хостинг: Vercel / Netlify / GitHub Pages

## Этапы
1. **Прототип.** Вращающийся глобус с границами, клик по стране → карточка (флаг, столица, 3 факта), переключатель RU/EN.
2. **Пазл на одном континенте (Европа).** Рассыпание, перетаскивание, примагничивание, звуки.
3. **Весь мир + океаны.** Уровни сложности (подсказки-контуры, поворот детали), таймер, прогресс, мелкие страны (группы/подсветка).
4. **Выпуск.** Деплой, PWA, проверка на телефоне, при желании — сторы.

### Визуальные улучшения (решено 23.11.2026)
Глобус — **в начале этапа 2** (от этого зависит вид деталей пазла):
- Океан с рельефом дна и бликом солнца вместо однотонного синего.
- Объём у стран: лёгкое выдавливание над океаном, мягкие тени по краям — детали как настоящие кусочки пазла.
- Продуманная палитра: соседние страны никогда не одного цвета (раскраска графа соседства).
- Подписи крупных стран прямо на глобусе при приближении.

Интерфейс — **перед этапом 4** (можно раньше, если останется время):
- Свой шрифт и стиль карточки: картинка-иллюстрация, иконки для фактов.
- Анимации: плавное появление карточки, «пульс» выбранной страны.
- Стартовый экран с названием и кнопкой «Играть».

## Статус
**Этап 1 готов (23.11.2026).** `npm run dev` → http://localhost:5173: вращающийся глобус (OrbitControls,
мышь и палец, автоповорот до первого касания и через 10 с простоя), подсветка при наведении, клик →
карточка (флаг, название, столица, 3 факта), глобус доворачивается к стране, точка столицы. RU/EN,
по умолчанию язык браузера, выбор хранится в localStorage. Консоль чистая, `npm run build` проходит.

Устройство:
- `scripts/build-data.mjs` (`npm run data`) — качает Natural Earth 50m, упрощает mapshaper →
  `public/data/borders.json` (242 страны, 260 КБ, props только `{id}` = ADM0_A3) и
  `data/countries.json` (id, iso2, name/capital ru+en, capitalLonLat, continent, flag).
  Без столицы 29 мелких территорий + Антарктида; без флага SOL, CYN, KAS.
- `data/facts/{africa,asia,oceania,europe,north-america,south-america}.json` — `{id: {ru:[3], en:[3]}}`,
  все 242 страны. Сгенерированы нейросетью, выборочно не проверялись.
- `src/geo/buildCountries.ts` — триангуляция полигонов (earcut из three) с дроблением
  треугольников > 3°, **отдельный меш на страну** (пригодится для пазла), линии границ одним LineSegments.
- `src/Globe.tsx` (сцена, океан-шар блокирует клики по обратной стороне), `src/CountryCard.tsx`,
  `src/data.ts` (факты подгружаются отдельным чанком), `src/i18n/`.

**Спорные территории — решено (23.11.2026): нейтральные детали.** 10 зон вырезаны из стран
в отдельные детали `D-*` (D-CRIMEA, D-WSAHARA, D-KASH-IN, D-KASH-PK, D-AKSAI, D-ARUNACHAL, D-GOLAN,
D-ABKHAZIA, D-SOSSETIA, D-TRANSNISTRIA): серые со штриховкой, карточка «Спорная территория» +
кто претендует / кто управляет, без фактов. TWN, KOS, CYN, SOL остаются странами с пометкой
«Признана частично». Тексты — `data/disputed.json`. SAH и KAS удалены (поглощены зонами), стран 240.
В пазле зоны — самостоятельные детали. Ссылка `#ID` в адресе открывает карточку (`#D-CRIMEA`, `#FRA`).

**Этап 2 готов (23.11.2026).**

Визуал (стиль выбран пользователем: «Игрушка»). Стили лежат в `src/globeStyles.ts` (toy по умолчанию, ещё atlas, vintage),
`?style=atlas` переключает стиль, `?compare` показывает три стиля рядом.
- Страны — плиты высотой `style.height` (`buildSlab` в `buildCountries.ts`): верх, стенки с затемнением внизу; у деталей пазла есть дно.
- Океан — шейдер `src/Ocean.tsx`: маска суши `geo/landMask.ts` (canvas 1024×512, размытие → шельф и тень у берега),
  шумовой рельеф дна, рябь, блик солнца от `sunDir` (свет у камеры).
- Палитра: раскраска графа соседства (`colorIndices`, соседи = общие вершины), спорные зоны серые.
- Подписи — `src/Labels.tsx` (DOM, без React-рендеров): чем ближе камера, тем мельче страны подписаны, без наложений. В пазле скрыты.

Пазл (`src/puzzle/`, грузится лениво отдельным чанком ~2 МБ вместе с Rapier):
- `pieces.ts`: Европа по NE без RUS + GEO, ARM, AZE, CYP, CYN, D-CRIMEA, D-TRANSNISTRIA, D-ABKHAZIA, D-SOSSETIA.
  Микрогосударства < 1000 км² (VAT, SMR, MCO, LIE, AND, MLT, JEY, GGY, IMN) остаются на основе. Заморские части
  (Гвиана, Канары) — тоже на основе (`rest`), в детали только полигоны в рамке Европы. Итого 47 деталей.
- `Puzzle.tsx`: Rapier без гравитации. Детали разлетаются от глобуса и пружинами плывут в «лоток»: слоты в пространстве
  камеры (`layout.ts`), на ПК две колонки слева и справа, на телефоне ряды сверху и снизу, под ними тёмная подложка.
  В лотке детали масштабируются под слот. Коллайдеры — шары (радиус слота).
- Перетаскивание: pointerdown по детали (плюс невидимая сфера-ручка) → кинематическое тело. Над шаром деталь
  поворачивается к точке касания (поворот вокруг центра глобуса), вне шара лежит в плоскости лотка. Магнит: центр
  ближе ~26 px к своему месту (на тач 34 px) → деталь прыгает на место, при отпускании встаёт. Иначе возвращается в лоток.
  На тач деталь висит на 56 px выше пальца.
- Кнопка «💡 Подсказка»: 3 раза за блок (`HINTS_PER_BLOCK` в `App.tsx`). Случайная деталь из лотка сама
  летит на место по дуге за 1,1 с (режим `snap` с `snapTime`).
- После того как деталь встала, над ней появляется название (drei `Html`, кнопка `.placed-label`). Клик по названию
  открывает карточку страны, клик по пустому месту прячет название. После сборки глобус снова кликабелен.
- Звуки синтезируются Web Audio (`sounds.ts`), кнопка 🔊. Счётчик с полоской, «Европа собрана!», «Ещё раз», «Выйти».
- Проверено автоматически: все 47 деталей собраны мышью на 1280×720 и касаниями на 375×812, консоль чистая, build проходит.
- Для автотестов в DEV: `window.__advance` (шаг кадра r3f; панель браузера бывает скрыта, тогда rAF стоит) и
  `window.__puzzle` (runtimes, camera).

(север вправо), горизонтальный drag крутит глобус вокруг оси, вертикальный — смотреть сверху/снизу (−35°…70°), колесо/щипок — зум.
Глобус по-прежнему стоит в начале координат и не вращается; камера ездит вокруг земной оси, а «комната» (`view.frame` =
Ry(theta)·Rz(TILT)) едет с ней, поэтому на экране крутится только глобус. API для пазла: `controls.enabled`, `controls.update()`
(подхватывает камеру, сдвинутую кодом). `setViewOffset` поднимает глобус на экране, чтобы была видна подставка (только в
старинном стиле и не в пазле; передавать реальный aspect — иначе картинка растягивается). `src/Interior.tsx` (только старинный
стиль): бронзовая подставка, полукольцо-меридиан, штифты на полюсах, стол из ореха, обои, панели, книги, тёплая лампа.
В лотке детали повёрнуты так же, как их место на наклонённом глобусе. DEV: `window.__view`.

## Экономия токенов (обязательно)
1. **Этот файл — единственный источник контекста.** Новая сессия читает только его и нужные
   файлы кода, не пересказывает историю. Решения и статус записывать сюда, а не держать в чате.
2. **Одна сессия = один этап или одна крупная задача.** Когда сессия становится тяжёлой
   (закончен этап, много скриншотов, длинная отладка) — обновить «Статус», открыть новую
   сессию с коротким заданием («читай CLAUDE.md, делаем этап N») и заархивировать старую.
3. **Большие данные никогда не читать в контекст.** GeoJSON, countries.json, факты —
   обрабатывать скриптами (`scripts/`), смотреть только итоговую сводку (кол-во стран, размер файла, ошибки).
4. **Механику — субагенту на Sonnet:** скачивание и конвертация данных, mapshaper,
   генерация и раскладка фактов по JSON, сборка, деплой. Задание короткое и самодостаточное,
   ответ в 2–3 строки. На Opus — архитектура, геометрия пазла, вкус и правки по замечаниям.
5. **Проверка в браузере:** сначала `read_console_messages` / `read_page` / `get_page_text`,
   скриншот — только когда важен вид, уменьшенный (`scale: 0.5`), один на проверку.
6. **Код мелкими модулями** (`Globe.tsx`, `CountryCard.tsx`, `puzzle/*.ts`, `geo/*.ts`),
   чтобы читать точечно, а не целые большие файлы. После правки файл не перечитывать.
7. **Факты генерировать пачками сразу в файл** (`data/facts/<континент>.json`), в чат не выводить.
